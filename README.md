# 橱窗陈列实时设计系统

面向连锁品牌橱窗陈列的浏览器内实时设计工具：按门店真实尺寸搭建橱窗、拖入主题物料与模特、实时碰撞/规则检查、批量适配全国门店，确认后生成带三视图与包装用量的方案文件。

- **技术栈**：TypeScript + 自研 WebGL2 引擎（无重型 3D 库依赖）+ IndexedDB 本地存储 + Vite
- **数据全部本地**：方案、门店档案、物料、套件、模特系列、确认书均存于浏览器 IndexedDB，无后端

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建到 dist/
npm test           # 16 项纯逻辑测试（碰撞/裁切/排版/规则/矩阵）
npm run typecheck
```

## 渲染引擎要点（`src/engine/`）

- **实例化渲染**：同 mesh+纹理的元素合并为一次 `drawElementsInstanced`，8 个元素仅 12 次 draw call；百件物料仍保持少量绘制批次。
- **零热路径分配**：实例缓冲（4096 容量）、UBO、灯光投影矩阵均预分配复用，连续调参不产生 GC 压力。
- **每实例属性**（location 3~7）：平移/旋转/缩放/基色/粗糙度/材质号/发光/拾取 ID，GPU 端组装模型矩阵。
- **材质**（`shaders.ts`）：亚克力菲涅尔边缘高光与透明层次、KT 覆膜亚光颗粒、木纹拼接缝、镀铬环境贴图反射、绒布掠射角 sheen、灯箱通电增饱和/断电发灰、玻璃起雾发花。
- **其他**：2048 阴影贴图 + 2×2 PCF、独立拾取 FBO（ID 编码到颜色）、半透明远→近排序、屏幕坐标→地台射线求交实现拖拽、轨道相机。

## 核心算法（`src/core/`）

- `rules.ts`：AABB 碰撞（含旋转包围盒）、门洞/货梯超限、KT 板按 1200×2400 标准板裁切编号、横杆间距容量、同色系连续占位/黄金视线区/配饰同组规则、包装体积与工时估算。
- `layout.ts`：按目标橱窗贪心自动重排（锁定道具不动）、主题批量挂接多门店并列出冲突、模板归一化坐标反归一化、教学模式三维度评分。
- `scene.ts`：领域模型→渲染实例、视线遮挡线段求交。

## 数据与持久化（`src/data/`）

- `db.ts`：IndexedDB 七个对象仓库的类型化封装。
- `store.ts`：内存读模型 + 订阅刷新 + 回收站 30 天到期清理。
- `seed.ts`：首次启动注入 12 件物料、3 个模特系列、5 家门店、3 套模板。

## 已验证

- `npm test`：16 项逻辑测试全部通过（碰撞、超限、KT 裁切、横杆容量、规则、包装工时、锁定重排、批量适配、模板、教学评分、矩阵求逆、射线拾取、地台 AABB）。
- 无头 Chrome WebGL2 冒烟：立方体/地面/玻璃/半透明材质正确上屏，软件渲染 135fps、draw call 批合并生效。
- `npm run build` 通过，产物 gzip 后约 36KB JS。
