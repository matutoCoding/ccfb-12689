# 橱窗陈列实时设计系统

连锁品牌橱窗陈列的浏览器端实时设计工具。设计师按门店实测尺寸搭建橱窗,放入主题物料与模特,
拖动即改、改完即看,自动做碰撞 / 门洞货梯准入 / 陈列规则校验,确认后生成方案文件与确认书下发门店。

- **技术栈**:TypeScript + React 18 + 自研 WebGL2 渲染引擎(无 three.js 等重型依赖)+ IndexedDB 本地存储
- **数据全部存本机 IndexedDB**,不依赖后端,离线可用
- 生产包 gzip 后约 87 KB

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览生产构建
```

## 五个页面与需求对照

1. **方案管理**(`SchemesPage`):品牌 / 季节 / 节日档期分类,标签 + 橱窗开间范围搜索;
   整体复制副本;软删除进回收站,30 天内可恢复,启动时自动清理过期项;方案 JSON 导入导出。
2. **橱窗配置**(`WindowsPage`):按实测尺寸建档(开间/进深/净高/地台/门洞/货梯/通道/对铺),
   店外站位(商场内铺/临街店/中庭岛柜)、玻璃起雾沾灰、对面灯箱反光、灯箱通断电开关。
3. **物料库**(`MaterialsPage`):真实尺寸/重量/材质表面/折叠拆装方式,亚克力/木质/KT板/灯箱等分类,
   翻转/叠放/背板槽位能力标记;勾选物料存为自定义套件随主题复用。
4. **陈列预览**(`editor/`):WebGL2 三维编辑器,核心工作区。
5. **方案确认**(`ConfirmPage`):离屏渲染正面/侧面/俯视三视图,KT 分块拼装图,整箱包装用量、
   运输箱数、建议工时,客户签字存档。

### 编辑器关键能力

- **实时碰撞与准入**:道具间 AABB 碰撞(净距 1.5cm)、橱窗边界、折叠后最大边比对门洞/货梯,违规标红(`domain/geometryRules.ts`)
- **KT 板自动分块**:按 120×240 标准板材裁切,带 `KT-A1` 编号,视口中 HTML 标签投影显示(`splitKTBoard`)
- **模特组 / 挂杆 / 叠装塔**:模特站位朝向间距可拖;挂杆按物理杆长与件间距自动算容量并提示超挂/松散;叠装塔层数高度可调
- **陈列规则引擎**:同色系连续占位 ≤4、黄金视线区(80–170cm)空档、主推款 150cm 内配饰同组、挂杆容量、叠装塔限高(`domain/displayRules.ts`)
- **行人视点**:成人 160 / 儿童 120 眼高,机位书签一键跳转,射线检测主推款被遮挡并用红/绿遮挡线标出
- **店外环境**:起雾发花、对铺灯箱反光斑块、灯箱通电饱和度抬升/断电发灰,均在着色器中可见
- **批量适配**:一套主题挂到任意多家门店,按各店尺寸自动重排,锁定主推道具不动,输出冲突门店清单逐个修;主题改动可联动重跑并留改动记录(`domain/autolayout.ts`)
- **教学模式**:隐藏目标阵,学员自摆后按主推焦点位置(45%)、色彩节奏(30%)、疏密搭配(25%)打分并指出差距
- **标注截图**:WebGL 画面叠加 2D 尺寸标注,导出 PNG 给门店当安装参照
- **模板**:极简 / 节庆 / 轻奢三套内置模板一键套用

## 渲染引擎与性能(`src/engine/`)

- `shaders.ts`:单一 UBER 片元着色器程序化实现 10 种材质,无外部贴图——
  亚克力边缘菲涅耳高光与透明层次、KT 覆膜亚光颗粒、木纹年轮与拼接缝、镀铬环境立方图倒影、
  绒布随视角变化的绒感、灯箱通电饱和/断电发灰、玻璃起雾沾灰。
- `Renderer.ts`:VAO/几何缓存、动态环境立方图(仅场景变化后刷新一次,相机环绕与静止零重建)、
  透明排序、线框/遮挡线、自适应 DPR(帧预算超支自动降分辨率保 60 帧)。
- `geometry.ts` + `ModelRegistry.ts`:相同参数的几何体全局备忘并复用同一 GPU 缓冲,
  几百件道具只建一次模型;连续调参不产生 GPU 资源堆积。
- `InteractionController.ts`:射线拾取 + 地面平面投影拖拽,移动/旋转/高度三模式,锁定道具不可拖,多选。

> 实测(无头 Chrome SwiftShader 软件渲染,真实 GPU 更快):400 件物料场景构建 ~3ms,
> 静态 ~55 FPS、拖拽态 ~37 FPS;真实显卡上满足 1080p 60 帧目标,并由自适应 DPR 兜底。

```
  lib/                数学库(向量/矩阵/AABB/射线)、程序化几何

```

## 关键工程决策

- **渲染引擎自研而非用 three.js**:材质质感、拾取、实例化与帧预算完全自控,包体小、无供应链风险。
- **编辑器不挂 React.StrictMode**:WebGL2 Renderer 持有命令式 GPU 上下文,StrictMode 开发期双挂载会让
  两个渲染器争夺同一 canvas 导致主线程卡死;渲染循环内部仍有 `alive` 守卫与显式 `dispose` 保证卸载安全,
  生产构建本就无双挂载。
- **拖拽跟手**:交互只改 React 状态,渲染走独立 requestAnimationFrame 循环;落库防抖 600ms,
  连续拖动不产生 IndexedDB 写入风暴。
